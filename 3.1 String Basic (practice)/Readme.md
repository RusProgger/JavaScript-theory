# 🧪 Практика по строкам в JavaScript

Здесь находятся простые, но полезные задания для закрепления работы со строками в JavaScript (Vanilla JS).  
Упражнения помогут лучше понять переменные, шаблонные строки, `prompt`, вывод, и базовую логику.

---

## 🔰 Уровень 1 — Простые строки и вывод

### ✅ Задание 1: Приветствие пользователя
- Спроси имя у пользователя через `prompt`
- Выведи на страницу фразу: `Привет, <имя>!`, убрав лишние пробелы

### ✅ Задание 2: Конкатенация строк
- Создай переменные:  
  `let first = "Good";`  
  `let second = "morning";`
- Выведи в консоль: `Good morning!`

### ✅ Задание 3: Перевод в верхний регистр
- Пусть пользователь введёт любое слово
- Выведи это слово в **верхнем регистре**

---

## 🔁 Уровень 2 — Работа со строками и шаблонами

### ✅ Задание 4: Длина имени
- Спроси имя у пользователя
- Выведи: `Ваше имя содержит <число> букв`

### ✅ Задание 5: Проверка имени
- Если пользователь ввёл имя `"admin"` — выведи: `Добро пожаловать, админ!`
- Иначе: `Привет, пользователь!`

### ✅ Задание 6: Добавление символов
- Введи строку через `prompt`
- Добавь к ней в конце `!!!` и выведи результат

---

## 🔍 Уровень 3 — Условия и логика

### ✅ Задание 7: Проверка на пустую строку
- Если пользователь нажал OK, но оставил поле пустым (или только пробелы) — выведи: `Вы ничего не ввели!`
- Иначе — выведи имя

### ✅ Задание 8: Последний символ строки
- Пусть пользователь вводит слово
- Выведи **последний символ** этой строки

---

## 🎁 Бонус — немного интереснее

### ✅ Задание 9: Обратное имя
- Пусть пользователь введёт имя
- Выведи это имя в **обратном порядке**, например:  
  `Alex` → `xelA`

> Подсказка: используй `.split('')`, `.reverse()`, `.join('')`

---

## 📌 Цель
Закрепить базовые навыки:
- Работа со строками
- Шаблонные строки
- `prompt()` и `document.write()`
- Условия (`if/else`)
- Методы строк: `trim()`, `toUpperCase()`, `length`, `charAt()`, `slice()`, и др.
