# 🧪 Практика по условиям и циклам в JavaScript

Здесь собраны простые, но полезные задания для закрепления темы **условий и циклов** в JavaScript (Vanilla JS).  
Упражнения помогут лучше понять логику программ, работу с `if`, `else`, `else if`, циклами `for` и `while`.

---

## 🔰 Уровень 1 — Условия и ветвления

### ✅ Задание 1: Проверка возраста
- Спроси возраст пользователя через `prompt`
- Если возраст 18 или больше — выведи: `Доступ разрешён`
- Иначе — `Доступ запрещён`

---

### ✅ Задание 2: Чётное или нечётное
- Спроси у пользователя число
- Выведи:
  - `Чётное`, если делится на 2 без остатка
  - `Нечётное` — в остальных случаях

---

### ✅ Задание 3: Оценка результата
- Пусть у пользователя есть переменная `score`
- Если `score >= 90`, выведи: `Отлично!`  
  Если `score >= 70`, но меньше 90 — `Хорошо`  
  Если `score >= 50`, но меньше 70 — `Удовлетворительно`  
  Иначе — `Плохо`

## 🧠 Уровень 3 — Условия + циклы

### ✅ Задание 7: Сумма чисел от 1 до N
- Спроси у пользователя число `N`
- Посчитай и выведи **сумму** всех чисел от 1 до `N`  
Пример: `N = 4` → `1 + 2 + 3 + 4 = 10`

---

### ✅ Задание 8: Угадай число
- Задай число в переменной (например, `let secret = 7`)
- Через `prompt` проси пользователя ввести число
- Подсказывай:
- Если число меньше — `Мало`
- Если больше — `Много`
- Повторяй попытки, пока не угадает — тогда: `Угадал!`

---

### ✅ Задание 9: Проверка логина
- Спроси логин у пользователя
- Если это `"admin"` — спроси пароль
- Если пароль `"1234"` — выведи: `Добро пожаловать, админ!`
- Иначе: `Неверный пароль`
- Если логин не `"admin"` — выведи: `Привет, гость!`
