# JavaScript Practice

## Task

🔹 Создайте массив объектов `Car`.

Каждый объект должен содержать следующие свойства:

- Название машины
- Цвет машины
- Год выпуска

### Requirements

- Добавьте 5 машин в массив
- Выведите информацию о каждой машине на экран

const cars = [
    {
        name: "BMW",
